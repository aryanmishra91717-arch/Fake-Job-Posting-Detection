# Fake Job Posting Detection Using Machine Learning

## Project Overview
Fake Job Posting Detection is an AI-based application developed to identify fraudulent job advertisements using Machine Learning and Natural Language Processing (NLP).

The system analyzes job-related information and predicts whether a job posting is genuine or fraudulent.

## Objectives
- Detect fake job advertisements.
- Analyze job descriptions using NLP.
- Help users identify potentially fraudulent recruitment posts.

## Technologies Used
- Python
- Machine Learning
- Natural Language Processing (NLP)
- TF-IDF Vectorization
- Scikit-learn

## Machine Learning Algorithms
- Logistic Regression
- Random Forest

## Project Features
- Job title and description analysis.
- Text preprocessing and feature extraction.
- Automated fake job prediction.
- Classification of job advertisements.

## Project Structure
- `app.py` – Main application
- `predict.py` – Prediction functionality
- `train_model.py` – Model training
- `check_data.py` – Dataset checking
- `fake_job_model.pkl` – Trained ML model
- `tfidf_vectorizer.pkl` – TF-IDF vectorizer
- `requirements.txt` – Project dependencies

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/aryanmishra91717-arch/Fake-Job-Posting-Detection.git`

2. Open the project folder.

3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `python app.py`

## Dataset
The project uses the Fake Job Postings dataset from Kaggle.

## Applications
- Online job portals
- Recruitment platforms
- Job seekers and applicants

## Conclusion
This project demonstrates how Machine Learning and NLP can be used to identify potentially fraudulent job advertisements and improve online recruitment safety.
